**Name:** Aibar Aben

## What I made

A simple photo gallery using HTML and CSS.

- Flexbox for the navigation and featured cards.
- CSS Grid for the photo gallery.
- 9 different photos from Unsplash.
- Hover effects for cards and gallery images.
- Responsive layout for smaller screens.

## Tasks

### Task 0 — Navigation Bar
Header with a logo and navigation links. Flexbox is used for alignment.

### Task 1 — Card Row
Three photo cards are displayed in one row using Flexbox.

### Task 2 — Grid Layout
The page contains separate sections and uses Grid for the main layouts.

### Task 3 — Image Gallery
Nine photos are arranged in a CSS Grid. Hovering over a photo shows its name.

### Task 4 — Combining Flexbox and Grid
Flexbox and Grid are used together on the page.

## How to run

Open `index.html` in a browser.
